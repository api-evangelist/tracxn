# Tracxn

> Tracxn is a market intelligence platform for private company data — 7.7M+ companies across 2,000+ sectors and 3K+ feeds — used by VC, PE, investment banking and corporate M&A teams. Programmatic access ships as Data Solutions: the Tracxn API v2.2 (JSON over HTTPS), an official Tracxn MCP server for AI assistants, scheduled SFTP dumps, and Snowflake/BigQuery integrations. No public /llms.txt is published; this file was generated by API Evangelist from the catalog — verify details against Tracxn's own site.

## APIs
- [Tracxn API (developer page)](https://w.tracxn.com/api-developers-page): POST query endpoints at https://platform.tracxn.com/api/2.2 — /companies, /investors, /transactions, /acquisitiontransactions — authenticated with an `accesstoken` header; Playground sandbox under /api/2.2/playground.
- [API documentation (platform login required)](https://platform.tracxn.com/a/api/gettingstarted/apibasics)
- [Official Postman workspace](https://www.postman.com/tracxnapi/tracxn-api/overview)

## MCP
- [Tracxn MCP](https://w.tracxn.com/tracxn-mcp): official connector for Claude, ChatGPT, Gemini, Cursor and other MCP clients; enable at https://platform.tracxn.com/a/integrations#a:ai-integrations (subscription with MCP access required).
